# Trabajo Practico - Parte 2
Con la ayuda de la IA actualizar el backend de la app de persona

* Agregar el DELETE para que /persona/1 borre la persona DNI 1
 * API -> Servicio -> Recupera y se fija si existe -> Repositorio
* Agregar el PUT para modificar una persona si existe. Debería ser PUT /persona/1 para modificar el nombre (que va en el body) de la persona con DNI 1
 * API -> Servicio -> Recupera y se fija si existe -> Le modifica los datos -> Repositorio
* Si la persona no existe (según su DNI), devolver un 400.
