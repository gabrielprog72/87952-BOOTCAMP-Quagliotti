Cliente REST de personas

Consultá, agregá, modificá o eliminá personas. Antes de modificar o eliminar se pide confirmación.

GET sin ID trae la lista y con ID trae una persona. En POST el ID es opcional: si no lo indicás, se usa el más alto + 1. PUT y DELETE necesitan el ID. El ID puede ir en el campo o en el body.
